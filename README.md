# StivelyShop-E-Commerce Frontend

StivelyShop is a modern and responsive fashion/lifestyle e-commerce frontend built as part of a Frontend Development Internship.
The application provides a complete shopping experience including product browsing,search,filtering,sorting,product detailscart management,checkout,order confirmation.


## Features
- Responsive navbar with mobile menu
- Hero section
- Shop by category
- Featured products
- Best sellers
- Product search
- Category filtering
- Price filtering
- Rating filtering
- Product sorting
- Pagination
- Product details page
- Related products
- Add to cart
- Update cart quantity
- remove products from cart
- cart data stored in localStorage
- checkout form with validation
- Payment method selection
- Order summary
- Order confirmation with generated order ID
- Loading, error and empty states
- responsive design for desktop,tablet and mobile phone

## Api

- Product and category data are fetched from the DummyJSON API.
- https://dummyjson.com/products
- https://dummyjson.com/products/:id
- https://dummyjson.com/products/categories
